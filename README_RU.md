# AppMixer — сборка и настройка (инструкция для владельца мака)

Пер-прикладной микшер громкости «как в Windows»: иконка в меню-баре, сверху
общая громкость, ниже — по слайдеру на каждое запущенное приложение. Все
запущенные приложения видны в списке сразу, ещё до первого звука — громкость
можно задать заранее, и она применится с первым звуком приложения.

Громкость каждого приложения — до 200 % (+6 дБ): выше 100 % зона подсвечена,
усиленные пики мягко ограничиваются, без жёсткого клиппинга. На слайдере
магнитные отметки 50 / 100 / 150 % — двигаются мимо и «прилипают»; отметка
100 % особая: это родной, необработанный звук приложения (tap отключается).

Без драйверов: основан на Core Audio Process Tap API (macOS 14.4+). Приложения,
которые вы не трогали (100%), вообще не проходят через микшер. Если AppMixer
выключить или он упадёт — звук всех приложений мгновенно вернётся к обычному,
«пропадание звука навсегда» невозможно по построению.

## Сборка на маке (один раз)

Нужны: macOS 15+ (у вас Tahoe — ок), Xcode, xcodegen.

```sh
cd AppMixer
brew install xcodegen     # если ещё нет
xcodegen                  # создаст AppMixer.xcodeproj
open AppMixer.xcodeproj
```

В Xcode:
1. Слева сверху выбрать схему **AppMixer**.
2. Signing & Capabilities: Team = ваш Apple ID (кнопка Add Account, если нет —
   бесплатного хватит), галочка Automatically manage signing.
3. **Cmd+R** (Run).

## Первый запуск

- Появится иконка в меню-баре. Откройте поповер, запустите музыку/видео в любом
  приложении, подвигайте его слайдер.
- macOS спросит разрешение на запись системного звука — **Разрешить**.
- Если баннер «Audio access needed» не исчез — Системные настройки →
  Конфиденциальность и безопасность → Запись системного звука → включить AppMixer.

## Важно про пересборки и разрешение

macOS привязывает разрешение к подписи приложения. Пока собираете через Xcode
под своим Apple ID — подпись стабильна, разрешение запоминается. Если собирать
без подписи (`make build`), после каждой пересборки разрешение будут спрашивать
заново — это нормально, не баг.

## Автозапуск

Правый клик (или Ctrl+клик) по иконке в меню-баре → **Launch at Login**.

## Проверка отказоустойчивости (сделайте разок)

1. Настройте разную громкость в 2–3 приложениях.
2. Принудительно убейте AppMixer (Activity Monitor → AppMixer → Quit).
3. Звук всех приложений мгновенно вернётся на 100% — так и задумано.

## Если что-то не собирается

Пришлите текст ошибки из Xcode целиком — правим. Скорее всего 1–2 итерации.

## Чек-лист приёмки

- [ ] Приложение в списке остаётся после того, как замолчало
- [ ] Подключить/отключить наушники — слайдеры продолжают работать
- [ ] Сон/пробуждение — работает
- [ ] Перезагрузка — громкости и автозапуск сохранились
- [ ] Убийство AppMixer — звук мгновенно вернулся
